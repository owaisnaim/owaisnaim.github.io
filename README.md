## Architecture & Design

Built with functional minimalism inspired by Linear, Vercel, and Apple engineering design systems:

- **Bento Grid Architecture**: Modular information design optimized for quick scanning by engineering leaders and recruiters.
- **Interactive Developer Terminal**: Tabbed simulator displaying live backend contracts, architecture manifests, and tech matrices with zero layout shift.
- **Command Palette (`Cmd + K` / `Ctrl + K`)**: Keyboard-navigable quick search for instant section jumping and actions.
- **Hardware-Accelerated Smooth Scrolling**: Native viewport scrolling synchronized with `requestAnimationFrame`.
- **Responsive & Accessible**: Native safe-area support, touch-optimized controls, and zero cumulative layout shift (CLS).
